# 셔틀 스매시

CPU와 1:1로 겨루는 배드민턴 게임입니다. 설치가 따로 필요 없고, 한 번 열어 두면 인터넷이 없어도 플레이할 수 있습니다.

## 아이폰에 설치하기

1. Safari에서 게임 주소를 엽니다.
2. 아래쪽 공유 버튼(□↑)을 누르고 **홈 화면에 추가**를 고릅니다.
3. 홈 화면의 **셔틀 스매시** 아이콘으로 실행합니다. 이후에는 비행기 모드에서도 됩니다.

안드로이드는 Chrome 메뉴의 **홈 화면에 추가**(또는 **앱 설치**)를, PC는 주소창 오른쪽의 설치 아이콘을 쓰면 됩니다.

## 조작

| | 키보드 | 터치 |
|---|---|---|
| 이동 | A / D, ← / → | ◀ ▶ |
| 점프 | W, ↑ | ⤒ |
| 스윙·서브 | Space, J | 🏸 |

스윙할 때 뒤로 누르고 있으면 클리어, 앞으로 누르고 있으면 드롭샷이 나갑니다. 점프 중에 머리 위 셔틀을 치면 스매시입니다. 11점 선승이고, 10:10부터는 2점 차가 나야 끝납니다.

## 업데이트할 때

게임 파일을 고친 뒤 `sw.js`의 `VERSION` 값을 올려야 이미 설치한 사람들에게도 새 버전이 전달됩니다.
